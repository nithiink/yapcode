Claude Sessions — card enclosure options

Same option-F content inside each session — what changes is the container. Four ways to enclose each session in a card so they're easy to tell apart. Sessions sit in a vertical stack with a gap between cards (no more hairline-divider runs).

1. Soft

Filled --panel card with a hairline border. Warm, calm, clearly grouped. The status strip steps up to --panel2 so it stays distinct inside the card.
