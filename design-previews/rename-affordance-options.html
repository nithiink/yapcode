Session rename — affordance options

How to signal “click to rename this session”. Hover each name to see the interaction.

Each is shown on the outlined session card, with the real Anton title. The whole name stays clickable to start renaming.

A. No icon — underline on hover
Cleanest. No glyph competing with the title; on hover the name gets a dashed underline and a tiny “click to rename” hint. The whole title is the target.
click to rename
B. Pencil on hover (thin)
A light pencil fades in only when you hover the name — no persistent clutter. Thinner stroke so it sits better next to the heavy caps.
C. Separated icon button
A distinct, always-visible little button set apart from the title — unambiguously a control, never crowding the text. Clearest target, slightly more UI.

D. Pencil-line glyph, always faint
Like today but a different icon (pencil-with-line) that reads better at small size, kept faint by default and brightening on hover. Discoverable without a hover.
E. “Rename” text on hover
No icon at all — a small uppercase “rename” word appears beside the title on hover. Explicit and unmistakable; uses a word instead of a glyph.

F. Framed pencil on hover
A boxed “edit document” icon that fades in on hover — heavier, more literal “edit” metaphor than the bare pencil.
