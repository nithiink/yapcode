# Yuri Phase 7 — Multi-Agent Mission Orchestration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn a Yuri mission from one session with one hardcoded step into a workflow of tasks, each dispatched to a named specialist backed by a provider, with dependencies, handoffs, verification and bounded retry.

**Architecture:** A new `WorkflowEngine` owns one decision — what runs next — and reaches providers only through the existing `SessionService`. Tasks name a *role*; a new roster of `Specialist` rows resolves role → specialist → provider at dispatch time. Personas are delegated to each provider's native agent system (`claude --agents`, OpenCode's `POST /session {agent}`) through a `SpecialistMaterialiser` seam rather than reimplemented as prompt injection.

**Tech Stack:** Python 3.14 (`backend/.venv`), FastAPI, sqlite3 (hand-rolled migrations), `unittest`. Frontend: Next 16.2.6 / React 19.2.6 / TypeScript 5.6.3, tests via `node --test lib/*.test.ts` only (no jsdom, no RTL).

**Spec:** `docs/superpowers/specs/2026-09-04-yuri-phase-7-design.md` — read it alongside this plan; every task's rationale is there.

## Global Constraints

- **Backend tests:** `cd backend && .venv/bin/python -m unittest discover -s tests -q`. All 624 existing tests must stay green at every commit.
- **Frontend tests:** `cd frontend && node --test lib/*.test.ts`. All 120 existing must stay green. There is **no** jsdom/RTL harness — logic under test must live in `lib/*.ts` as pure functions.
- **Typecheck/build:** `cd frontend && npx tsc --noEmit && npm run build` must pass.
- **`_JSON_COLS` must gain** `tools`, `capabilities`, `requires`, `verification`; **`_BOOL_COLS` must gain** `builtin`, `archived`, `read_only` (`backend/yuri/store/sqlite.py:28-29`). Missing one round-trips the column wrong with **no exception**.
- **No `frozenset` on any dataclass field that maps to a JSON column.** `_to_row` uses `json.dumps(v, default=str)`, which silently stores `"frozenset({'x'})"`. Use `tuple[str, ...]` and coerce in `__post_init__`.
- **Every new `EventType` needs exactly one entry in `NARRATION_OWNER`** (`backend/yuri/narration/policy.py`) or `tests/test_narration_policy.py` fails. This is the gate that caught `mission.deleted`.
- **Every new HTTP method needs its Next proxy export** in `frontend/app/api/yuri/[...path]/route.ts`. A missing export answers 405 regardless of the backend. This has now bitten twice (`PUT`, then `DELETE`).
- **`MAX_WRITERS = 1`.** Never dispatch two writing tasks concurrently — there is no worktree isolation, so two agents in one tree corrupt it.
- **A verification check that cannot run reports `unavailable`, and `unavailable` FAILS the task.** Never pass a check that did not execute.
- **No task may create tasks.** Only `WorkflowEngine.create` and the explicit append API write to `tasks`; neither is reachable from a provider. This is what makes the §12 bounds meaningful.
- **Voice tools never create, edit or delete a specialist**, and never delete anything. Destructive and prompt-authoring operations are UI/API only.
- Branch off `main`; commit per task.

"""Specialist — a named agent (spec §5).

An "agent" used to mean a provider binary. A Specialist is the thing the user
actually creates and names: a role, a job description, a toolset, and the
provider that runs it. Yuri's own persona is unaffected — she is still the
only voice; a specialist's prompt is a job description, not a character.
"""
from __future__ import annotations

import re
from dataclasses import asdict, dataclass, field

from .ids import new_id, utcnow

ROLES: tuple[str, ...] = ("researcher", "developer", "tester", "reviewer",
                          "verifier", "documenter")

TASK_CAPABILITIES: tuple[str, ...] = ("coding", "code_review", "research",
                                      "testing", "terminal", "browser", "git", "docs")

_SLUG_STRIP = re.compile(r"[^a-z0-9]+")


def slugify(name: str) -> str:
    """A provider-safe id. It becomes `--agent <slug>` on a command line and
    `<slug>.md` in OpenCode's config directory, so it must survive neither
    shell quoting nor path traversal: lowercase, [a-z0-9-] only, non-empty."""
    slug = _SLUG_STRIP.sub("-", name.strip().lower()).strip("-")
    return slug or f"agent-{new_id()[:8]}"


@dataclass
class Specialist:
    name: str
    role: str
    provider_id: str
    id: str = field(default_factory=new_id)
    slug: str = ""
    description: str = ""
    system_prompt: str = ""
    model: str | None = None
    tools: tuple[str, ...] = ()
    permission_mode: str = "default"
    capabilities: tuple[str, ...] = ()
    color: str = "#dd8a6a"
    builtin: bool = False
    archived: bool = False
    created_at: str = field(default_factory=utcnow)
    updated_at: str = field(default_factory=utcnow)

    def __post_init__(self) -> None:
        if self.role not in ROLES:
            raise ValueError(f"unknown role: {self.role!r}; expected one of {list(ROLES)}")
        # Tuples, not sets: see the module note in sqlite.py's _JSON_COLS.
        # from_dict hands us lists straight out of json.loads.
        self.tools = tuple(self.tools)
        self.capabilities = tuple(self.capabilities)
        for cap in self.capabilities:
            if cap not in TASK_CAPABILITIES:
                raise ValueError(f"unknown capability: {cap!r}")
        # Derived once. A rename must NOT move it: a running session was
        # launched with the old slug and would lose its agent.
        if not self.slug:
            self.slug = slugify(self.name)

    def to_dict(self) -> dict:
        return asdict(self)

    @classmethod
    def from_dict(cls, d: dict) -> "Specialist":
        return cls(**{k: d[k] for k in cls.__dataclass_fields__ if k in d})

class TaskTransitionTests(unittest.TestCase):
    def _task(self, status="pending"):
        return Task(workflow_id="w1", ordinal=0, title="t", status=status)

    def test_the_happy_path_is_walkable(self):
        t = self._task()
        for nxt in ["ready", "dispatched", "running", "verifying", "completed"]:
            self.assertTrue(t.transition(nxt), nxt)
        self.assertIn(t.status, TERMINAL_TASK)

    def test_same_state_is_a_silent_no_op(self):
        t = self._task("running")
        self.assertFalse(t.transition("running"))

    def test_a_terminal_task_can_never_move_again(self):
        for status in TERMINAL_TASK:
            t = self._task(status)
            self.assertEqual(TASK_TRANSITIONS[status], frozenset(), status)
            with self.assertRaises(InvalidTaskTransition):
                t.transition("running")

    def test_pending_cannot_skip_straight_to_dispatched(self):
        # `ready` is the only gate that checks dependencies. Skipping it is how
        # a task would start before its dependency finished.
        with self.assertRaises(InvalidTaskTransition):
            self._task("pending").transition("dispatched")

    def test_dispatched_can_go_back_to_ready(self):
        # Reconciliation after a crash: dispatched with no session never
        # actually started, so it must be re-dispatchable (spec §13).
        self.assertTrue(self._task("dispatched").transition("ready"))

    def test_failed_can_retry_to_ready_or_give_up_to_blocked(self):
        self.assertIn("ready", TASK_TRANSITIONS["failed"])
        self.assertIn("blocked", TASK_TRANSITIONS["failed"])

    def test_blocked_is_terminal_for_now_but_a_human_can_retry_it(self):
        # blocked means attempts exhausted. It is NOT in TERMINAL_TASK, because
        # the user retrying it is the whole point of the state existing.
        self.assertNotIn("blocked", TERMINAL_TASK)
        self.assertIn("ready", TASK_TRANSITIONS["blocked"])

    def test_every_status_appears_in_the_table(self):
        # A status reachable by transition but absent as a key raises KeyError
        # deep inside transition() instead of failing here.
        reachable = {s for edges in TASK_TRANSITIONS.values() for s in edges}
        missing = reachable - set(TASK_TRANSITIONS)
        self.assertEqual(missing, set(), f"unreachable-from-table statuses: {missing}")

"""Task — one unit of work in a mission's workflow (spec §7.2).

Same shape as domain/mission.py: the table below is the single source of
truth, and every service enforces it rather than re-deriving it. `mission.py`
says "there is no orchestrator"; Phase 7 adds one, and this is the machine it
drives.
"""
from __future__ import annotations

from dataclasses import asdict, dataclass, field

from .ids import new_id, utcnow
from .specialist import ROLES

TASK_KINDS: tuple[str, ...] = ("agent_task", "approval", "verification", "human_input")

# `completed` and `skipped` are done for good. `blocked` deliberately is NOT:
# it means "attempts exhausted, a human is needed", and the human retrying it
# is the reason the state exists.
TERMINAL_TASK: frozenset[str] = frozenset({"completed", "skipped", "cancelled"})

TASK_TRANSITIONS: dict[str, frozenset[str]] = {
    # `ready` is the ONLY gate that checks dependencies, so nothing may reach
    # `dispatched` without passing through it.
    "pending": frozenset({"ready", "skipped", "cancelled"}),
    "ready": frozenset({"dispatched", "skipped", "cancelled"}),
    # back to `ready`: reconciliation after a crash, where `dispatched` with no
    # session means it never actually started (spec §13).
    "dispatched": frozenset({"running", "ready", "failed", "cancelled"}),
    "running": frozenset({"verifying", "waiting_approval", "failed", "cancelled"}),
    "waiting_approval": frozenset({"running", "failed", "cancelled"}),
    "verifying": frozenset({"completed", "failed", "cancelled"}),
    "failed": frozenset({"ready", "blocked", "cancelled"}),
    "blocked": frozenset({"ready", "cancelled"}),
    "completed": frozenset(), "skipped": frozenset(), "cancelled": frozenset(),
}


class InvalidTaskTransition(ValueError):
    pass


@dataclass
class Task:
    workflow_id: str
    ordinal: int                       # authoring order, NOT execution order
    title: str
    id: str = field(default_factory=new_id)
    kind: str = "agent_task"
    role: str | None = None
    specialist_id: str | None = None   # pinned by the user, or chosen at dispatch
    session_id: str | None = None
    status: str = "pending"
    instruction: str = ""
    requires: tuple[str, ...] = ()     # task capabilities
    verification: tuple[str, ...] = ()
    read_only: bool = False            # eligible for parallel execution
    attempts: int = 0
    max_attempts: int = 2
    result: dict = field(default_factory=dict)
    error: str | None = None
    started_at: str | None = None
    ended_at: str | None = None
    created_at: str = field(default_factory=utcnow)
    updated_at: str = field(default_factory=utcnow)

    def __post_init__(self) -> None:
        if self.kind not in TASK_KINDS:
            raise ValueError(f"unknown task kind: {self.kind!r}")
        if self.role is not None and self.role not in ROLES:
            raise ValueError(f"unknown role: {self.role!r}")
        # Tuples, not sets — see sqlite.py's _JSON_COLS note.
        self.requires = tuple(self.requires)
        self.verification = tuple(self.verification)
        # An agent_task with neither a role nor a specialist cannot be
        # dispatched to anything, and the failure would surface at run time as
        # "no candidates" long after the workflow was accepted.
        if self.kind == "agent_task" and not (self.role or self.specialist_id):
            raise ValueError("an agent_task needs a role or a specialist_id")

    def transition(self, to: str) -> bool:
        if to == self.status:
            return False
        allowed = TASK_TRANSITIONS.get(self.status)
        if allowed is None or to not in allowed:
            raise InvalidTaskTransition(
                f"task {self.id[:8]}: {self.status} → {to} is not allowed")
        self.status = to
        self.updated_at = utcnow()
        if to == "running" and self.started_at is None:
            self.started_at = self.updated_at
        if to in TERMINAL_TASK or to == "blocked":
            self.ended_at = self.updated_at
        return True

    @property
    def is_terminal(self) -> bool:
        return self.status in TERMINAL_TASK

    @property
    def can_retry(self) -> bool:
        return self.attempts < self.max_attempts

    def to_dict(self) -> dict:
        return asdict(self)

    @classmethod
    def from_dict(cls, d: dict) -> "Task":
        return cls(**{k: d[k] for k in cls.__dataclass_fields__ if k in d})

    @abstractmethod

        history — the same reasoning as MissionService.delete detaching

class WorkflowRepo(ABC):

    @abstractmethod
    def get(self, id: str) -> Workflow | None: ...
    @abstractmethod
    def update(self, w: Workflow) -> None: ...
    @abstractmethod

class SqliteSpecialists(_Base, SpecialistRepo):
    table, cls = "specialists", Specialist

    def get_by_slug(self, slug):
        return self._one("SELECT * FROM specialists WHERE slug = ? AND archived = 0", (slug,))

    def get_by_name(self, name):
        return self._one("SELECT * FROM specialists WHERE name = ? AND archived = 0", (name,))

    def list(self, include_archived=False):
        if include_archived:
            return self._many("SELECT * FROM specialists ORDER BY role, name")
        return self._many("SELECT * FROM specialists WHERE archived = 0 ORDER BY role, name")


class SqliteWorkflows(_Base, WorkflowRepo):
    table, cls = "workflows", Workflow

    def for_mission(self, mission_id, live_only=False):
        if live_only:
            marks = ",".join("?" * len(LIVE_WORKFLOW))
            return self._many(
                f"SELECT * FROM workflows WHERE mission_id = ? AND status IN ({marks}) "
                "ORDER BY version DESC", (mission_id, *LIVE_WORKFLOW))
        return self._many(
            "SELECT * FROM workflows WHERE mission_id = ? ORDER BY version DESC", (mission_id,))

    def live(self):
        marks = ",".join("?" * len(LIVE_WORKFLOW))
        return self._many(f"SELECT * FROM workflows WHERE status IN ({marks})", LIVE_WORKFLOW)


class SqliteTasks(_Base, TaskRepo):
    table, cls = "tasks", Task

    def for_workflow(self, workflow_id):
        return self._many("SELECT * FROM tasks WHERE workflow_id = ? ORDER BY ordinal",
                          (workflow_id,))

    def add_dep(self, task_id, depends_on):
        self._c.get().execute(
            "INSERT OR IGNORE INTO task_deps (task_id, depends_on) VALUES (?, ?)",
            (task_id, depends_on))

    def deps_for(self, workflow_id):
        rows = self._c.get().execute(
            "SELECT d.task_id, d.depends_on FROM task_deps d "
            "JOIN tasks t ON t.id = d.task_id WHERE t.workflow_id = ?", (workflow_id,))
        out: dict[str, set[str]] = {}
        for task_id, depends_on in rows:
            out.setdefault(task_id, set()).add(depends_on)
        return out


class SqliteArtifacts(_Base, ArtifactRepo):
    table, cls = "artifacts", Artifact

    def for_mission(self, mission_id):
        return self._many("SELECT * FROM artifacts WHERE mission_id = ? ORDER BY created_at",
                          (mission_id,))

    def for_task(self, task_id):

Its six steps, in order, and each of them is load-bearing:

```python
async def advance(self, workflow_id: str) -> list[Task]:
    w = self.store.workflows.get(workflow_id)
    if w is None or w.status != "running":
        # A paused workflow that still dispatches is the worst bug this
        # design can have, so this is the first line and not a later check.
        return []
    tasks = {t.id: t for t in self.store.tasks.for_workflow(w.id)}
    deps = self.store.tasks.deps_for(w.id)

    # 2. pending -> ready when every dependency is done
    for t in tasks.values():
        if t.status != "pending":
            continue
        blockers = deps.get(t.id, set())
        if all(tasks[d].status in ("completed", "skipped") for d in blockers if d in tasks):
            t.transition("ready")
            self.store.tasks.update(t)

    # 3. concurrency budget from what is ALREADY in flight
    in_flight = [t for t in tasks.values()
                 if t.status in ("dispatched", "running", "verifying", "waiting_approval")]
    writers = sum(1 for t in in_flight if not t.read_only)
    readers = sum(1 for t in in_flight if t.read_only)

    started: list[Task] = []
    for t in sorted((x for x in tasks.values() if x.status == "ready"),
                    key=lambda x: x.ordinal):
        if t.read_only:
            if readers >= MAX_PARALLEL_READONLY:
                continue
        else:
            # A writer may not join ANY live task: a reader holding the tree
            # while a writer edits it is the same corruption by another route.
            if writers >= MAX_WRITERS or readers or writers:
                continue
        if not await self._dispatch_one(t, w):
            continue
        started.append(t)
        if t.read_only:
            readers += 1
        else:
            writers += 1

    # 5. deadlock: nothing running, nothing started, work remains
    remaining = [t for t in tasks.values()
                 if t.status not in ("completed", "skipped", "cancelled")]
    if not started and not in_flight and remaining:
        blocking = [t.title for t in remaining if t.status in ("blocked", "failed")] or \
                   [t.title for t in remaining]
        self._to_human(w, "deadlocked", blocking)
        return []

    # 6. all terminal -> complete the workflow and the mission
    if not remaining:
        self._complete(w)
    return started
```

`_dispatch_one` resolves the specialist (`roster.resolve(role, requires,
pinned=specialist_id)`), builds the instruction, calls `self.dispatch` and
returns False when `self.dispatch is None` (dry run) or when resolution
raises `NoSpecialist` — in which case the task goes to `failed` with the
resolver's actionable message, never silently stays `ready`.
